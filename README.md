# Version Check

Check dependency versions for npm, Cargo, Go modules, and Composer, and update them with one click via CodeLens or quick fixes.

## Supported Files

- `package.json` (npm)
- `Cargo.toml` (Rust/Cargo)
- `go.mod` (Go modules)
- `composer.json` (PHP/Composer)

## Commands

- `Version Check: Update Dependency`
- `Version Check: Refresh`

## Settings

- `versionCheck.cacheTtlSeconds`
- `versionCheck.providers.npm`
- `versionCheck.providers.cargo`
- `versionCheck.providers.go`
- `versionCheck.providers.composer`
